Most households we meet aren't missing an investment. They're missing the person coordinating the ones they have.

The portfolio is fine. The CPA is fine. The estate attorney is fine. But no one is holding the three of them to the same decision — and that gap is exactly where the return goes. If you've ever thought "someone should be watching how all of this fits together," you've already found the problem Driftwood exists to solve.
