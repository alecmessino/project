watershed-hero-static.svg — locked production export
====================================================

Geometry, color and weight are baked into presentation attributes. Nothing in
this file reads a CSS variable, a prop, or a <style> block; it renders
identically wherever it is dropped, including in renderers that discard CSS.

This is the ONLY production asset. An animated companion, watershed-hero.svg,
was cut — see "Why there is no animated file" at the end.

Locked values
  viewBox            370 52 680 626   (preserveAspectRatio="xMaxYMid meet")
  intrinsic size     none — the root carries NO width/height attributes. The viewBox
                     is the only intrinsic thing in the file, so it scales to
                     whatever box it is given and the 680:626 ratio is preserved
                     by the renderer rather than by a baked pixel pair.
                     NOTE: the Claude Design exporter writes width="680" height="626"
                     onto the root every time. Strip both after any re-export.
  presence           1.0  — full solid opacity, no fade, no mask
  boldness           0.75 — baked stroke widths: 9.75 / 15 / 18 / 21.75
  structure          12 feeders (4 clusters of 3) -> 4 junctions -> 2 -> 1 outflow
  feeder entry       straight horizontal x=390 to x=520, then curve
  feeder length      shortened; left caps land at x=390, clear of the text column
  outflow            x=902 to x=1052, butt cap, runs 2px past the right edge
  palette            #5d7e96 / #486e8a / #386280 / #2c5878 (tiers 1-4)

Files
  watershed-hero-static.svg   no animation, no <style> block — for screen, print,
                              PDF, email, and any renderer that drops CSS

Placement in the hero
  position:absolute; right:0; left:716px; top:50%; translateY(-50%);
  width:100%; max-width:max(0px, calc(100% - 716px));
  height:auto; aspect-ratio:680/626
  The 716px left edge keeps a 24px gutter from the 692px text column. That edge is
  now expressed as a width rather than only as an offset: width:100% asks for the
  whole box and the max-width clamp gives back exactly the 716px the text column
  owns, so the plate is fluid between the gutter and the right edge instead of
  being sized by a fixed pair. max() floors it at 0 — a container narrower than
  716px yields no width rather than a negative one.

  Below 1040px the plate drops into flow beneath the copy and bleeds right, and
  that rule MUST also send max-width:none. The clamp is measured off a left edge
  that no longer exists in flow; left unreset it starves the in-flow plate and
  collapses it to zero on any viewport under 716px.

Why there is no animated file
  watershed-hero.svg was dropped. Every export of it arrived without its <style>
  block: the class hooks (t1-t4, n2-n4) were in the markup but nothing defined
  them, so every path fell back to the SVG default of fill:black; stroke:none and
  the file rendered as solid black shapes — no palette, no tiered widths, no
  draw-on, no prefers-reduced-motion branch. Two separate exports were byte-for-byte
  identical, so this is not a one-off dropout.

  The cause is visible in what survived: 26 per-element animation-delay values came
  through intact because they are inline style ATTRIBUTES, while everything in the
  document-level <style> ELEMENT was discarded. The exporter carries attributes and
  drops the style block. That is also why this static file exports cleanly — all of
  its styling is presentation attributes.

  Re-exporting therefore cannot fix it. Reviving an animated version means either
  expressing the rules as attributes at the source (@keyframes and the
  reduced-motion query have no attribute form and would still be at risk), or
  hand-authoring the <style> block downstream and accepting that the file diverges
  from the Design project.

  Worth knowing if it is ever revived: an animated SVG only plays when inlined or
  loaded via <object>/<iframe>. Referenced from <img src> or background-image,
  SVG-internal CSS animation is suppressed by most browsers and it renders as the
  static state — which is this file.
